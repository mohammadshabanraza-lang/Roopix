# Deployment guide

1. Review all files and compare with the production GitHub branch.
2. Deploy from a dedicated branch and preview build first.
3. Verify `/`, `/beauty/`, `/exports/` and `/policies/` over HTTPS.
4. Verify sitemap XML at `https://roopix.in/sitemap.xml` and robots.txt.
5. Test external online-store, mailto, WhatsApp and map links.
6. Test all responsive breakpoints and motion preference behaviour.
7. Add real export products only after owner verification of product photos and specifications.
8. Do not deploy private credentials or configure a form endpoint without protected server-side secrets.

This package has not been pushed to GitHub or deployed to the live domain.
